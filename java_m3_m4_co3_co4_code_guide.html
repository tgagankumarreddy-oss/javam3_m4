Demo20.java

Inheritance using extends
extends · inheritance · IS-A relationship

Definition / Purpose

Demonstrates a superclass (Animal) and subclass (Dog). Dog inherits eat() from Animal and also has its own bark() method.

Code

// inheritance concepts
class Animal{
    void eat(){
        System.out.println("Animal is eating");
    }
}
class Dog extends Animal{
    void bark(){
        System.out.println("Dog is Barking");
    }
}
public class Demo20 {
    public static void main(String[] args) {
        Animal a=new Animal();
        Dog d=new Dog();
        System.out.println("this is output from parent class : ");
        a.eat();
        System.out.println("this below output from child class : ");
        d.bark();
        d.eat();
    }
}

Code Explanation

  1. Animal is the parent class and defines eat().
  2. Dog extends Animal, so Dog inherits eat().
  3. a is an Animal object and calls a.eat().
  4. d is a Dog object and calls its own bark().
  5. d.eat() works because eat() is inherited from Animal.
  6. This demonstrates the IS-A relationship: Dog IS-A Animal.

Output

this is output from parent class : 
Animal is eating
this below output from child class : 
Dog is Barking
Animal is eating

Try.java

try-catch-finally and input exceptions
try-catch-finally · ArithmeticException · InputMismatchException

Definition / Purpose

A safe division calculator using Scanner. It handles division by zero with ArithmeticException, invalid input with InputMismatchException, and closes the Scanner in finally.

Code

import java.util.Scanner;
import java.util.InputMismatchException;

public class Try {

    public static void main(String[] args) {
        // Create a Scanner object to read user input from the console
        Scanner scanner = new Scanner(System.in);

        System.out.println("=== Safe Division Calculator ===");

        try {
            // 1. Get the dividend
            System.out.print("Enter the dividend (e.g., 10): ");
            int dividend = scanner.nextInt();

            // 2. Get the divisor
            System.out.print("Enter the divisor (e.g., 0): ");
            int divisor = scanner.nextInt();

            // 3. Perform the division
            int result = dividend / divisor;
            System.out.println("\n✅ Success! Result: " + dividend + " / " + divisor + " = " + result);

        } catch (ArithmeticException e) {
            // Catches division-by-zero errors using System.out
            System.out.println("\n❌ Math Error: Cannot divide by zero!");
            System.out.println("Details: " + e.getMessage());

        } catch (InputMismatchException e) {
            // Catches non-integer inputs using System.out
            System.out.println("\n❌ Input Error: Please enter valid whole numbers (integers) only.");
        } finally {
            // Always close the scanner resource
            scanner.close();
            System.out.println("\n=== Scanner closed. Program finished. ===");
        }
    }
}

Code Explanation

  1. A Scanner reads two integers from the user.
  2. The division is performed inside try.
  3. If the divisor is zero, Java throws ArithmeticException.
  4. If the user enters something that is not an integer, nextInt() throws InputMismatchException.
  5. finally executes after the try/catch processing and closes the Scanner.
  6. The exact success/error output depends on the user's input.

Output

import java.io.FileReader;
import java.io.IOException;

public class ReadFile{
	public static void main(String[] args){
		try{
			FileReader fr=new FileReader("Student.txt");
			int ch;
			while((ch=fr.read())!=-1){
				System.out.print((char)ch);
			}
			fr.close();
		}
		catch (IOException e){
			System.out.println("error occured reading a file");
		}
	}
}

Code Explanation

  1. FileReader opens Student.txt.
  2. read() returns one character at a time as an integer.
  3. The loop continues until read() returns -1, meaning end of file.
  4. (char) ch converts the integer character value back to a character.
  5. close() closes the reader.
  6. IOException handles file-reading errors.

Demonstrates file creation, existence checking, filename/path information, size and permissions, writing, appending, reading, and deletion.

Code

import java.io.*;

public class MultipleFileOperations {
	public static void main(String[] args){
		File file=new File("Students.txt");
		try {
			//1.create a new file
			if (file.createNewFile()) {
				System.out.println("File created");
			} else {
				System.out.println("File already exists");
			}
			//2. check whether a file exists
			System.out.println("2.File Exists()" + file.exists());
			//3. get file name
			System.out.println("3.File Exists()" + file.getName());
			//4.Get absolute path
			System.out.println("4.File Path()" + file.getAbsolutePath());
			//5.file size
			System.out.println("5.File Size()" + file.length());
			//6.check read permissions
			System.out.println("6.read permissions()" + file.canRead());
			//7.check write permission
			System.out.println("7.write permssion()" + file.canWrite());
			//8.write data into file
			FileWriter fw = new FileWriter("Students.txt", true);
			fw.write("Name:Gagan Kumar\n");
			fw.write("Department:CSIT\n");
			fw.write("University:Kl university\n");
			fw.write("Subject:java\n");
			fw.close();
			System.out.println("Data added successfully");
			//9.Append data into file
			FileWriter append = new FileWriter("Students.txt", true);
			append.write("Topic:File Handling\n");
			append.close();
			System.out.println("Data appended successfully");
			//10.Read data from file
			BufferedReader br = new BufferedReader(new FileReader("Student.txt"));
			String line;
			System.out.println("\n10.File contents:");
			while ((line = br.readLine()) != null) {
				System.out.println(line);
			}
			br.close();
			//11.Get updated file size
			System.out.println("11.Updated file size" + file.length() + "bytes");
			//12.Delete file
			if (file.delete()){
				System.out.println("File deleted successfully");
			}
			else{
				System.out.println("Error deleting file");
			}


		}
		catch(IOException e){
			System.out.println("An error occurred."+e.getMessage());
		}

	}
}

Code Explanation

  1. File file = new File("Students.txt") represents Students.txt.
  2. createNewFile() creates the file if needed.
  3. exists(), getName(), getAbsolutePath(), length(), canRead(), and canWrite() inspect the file.
  4. A FileWriter appends student data to Students.txt.
  5. Another FileWriter appends the topic.
  6. A BufferedReader attempts to read Student.txt, not Students.txt.
  7. This is an important filename mismatch in the supplied code: the program writes to Students.txt but reads Student.txt.
  8. If Student.txt does not exist, the read step throws FileNotFoundException (an IOException), the catch block prints the error, and execution skips the remaining statements in the try block.
  9. If Student.txt does exist, it reads that file instead.
  10. Because deletion is after the read, it is reached only when no exception occurs before it.
